# Support

Thanks for using `datasheetindex`. Here is how to get help.

## Questions and bugs

- **Bugs and feature requests:** open an issue on the
  [issue tracker](https://github.com/Infineon/datasheetindex/issues). Please
  search existing issues first.
- **Usage questions:** start a thread in
  [GitHub Discussions](https://github.com/Infineon/datasheetindex/discussions).

## Infineon resources

- [Infineon Developer Community](https://community.infineon.com/) - forums and
  knowledge base
- [Infineon Developer Center](https://softwaretools.infineon.com/) - tools and
  software packages
- [Infineon product portfolio](https://www.infineon.com/cms/en/product/) - data
  sheets and product documentation

## Before opening an issue

Please include:

- The command you ran (or the API call) and the relevant output
- The characteristics of the input PDF (page count, layout, source)
- What you expected to happen

This makes it much faster to reproduce and resolve the problem.
